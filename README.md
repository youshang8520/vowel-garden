# 元音花园

元音花园是一款日语假名与入门日语学习 App。

当前发布为 Android 预览测试版，用于安装体验、学习流程测试和非商业个人使用。

## 安装

1. 在 Android 手机上下载 APK。
2. 如系统提示，允许从浏览器或文件管理器安装未知来源应用。
3. 打开 APK 安装。

如果手机上已有旧测试包，建议先卸载旧版本再安装。
