# 发布授权边界

最后更新：2026-06-19

本文件固定当前发布包的授权口径。它不是人工授权审查的替代品；正式发布前仍需要按验收清单确认音频、字体、笔顺和视觉素材的来源与可分发范围。

## 项目许可

- 项目源码和发布包使用 `Vowel Garden Non-Commercial Source License`。
- 允许个人学习、教学、研究、评估和非商用再分发。
- 禁止销售、商业培训、付费服务、广告投放、商用集成或其它商业用途，除非获得版权持有人书面许可。
- 第三方素材保留各自原许可证；项目非商用许可不会覆盖第三方素材的署名、相同方式共享或字体条款。

## 当前素材边界

| 类别 | 当前来源 | 当前发布口径 | 仍需发布前确认 |
| --- | --- | --- | --- |
| 课程源码 | 本项目贡献者 | 非商用源码许可 | GitHub 发布页需说明禁止商用 |
| 词语 SVG 图 | 项目生成素材 | 项目非商用许可 | 抽查图片是否无答案泄露 |
| 本地 WAV 音频 | 项目内生成/整理音频 | 仅随非商用预览包分发 | 发布前确认音频生成服务或来源条款 |
| 字体 | `assets/fonts/` 内随附字体说明 | 遵循字体自身许可证 | 发布包保留字体许可证说明 |
| 假名手写模型 | 项目内手写模型 | 项目非商用许可 | 继续用手写验证脚本防回退 |
| 汉字手写模型 | KanjiVG stroke path 派生数据 | 保留 KanjiVG CC BY-SA 3.0 署名和链接 | 复核 ShareAlike 边界和发布说明 |
| 笔顺动画 | 当前仍未作为完整正式素材接入 | 不声明完成 | 接入后必须记录来源、许可证和修改说明 |

## 发布包必须包含

- `LICENSE`
- `NOTICE.md`
- `README.md`
- `docs/release-license-boundary.md`
- `docs/release-license-boundary.json`
- `output/reports/acceptance-package.md`
- `output/reports/acceptance-package.json`

## 不得写成已完成的事项

- 真机人工体验验收未完成时，不写成已通过。
- 第三方音频或笔顺素材条款未复核时，不写成已授权商用。
- 笔顺动画未正式接入时，不写成已有动画覆盖。
- 本项目禁止商用，不能在发布说明中写成 ISC、MIT 或其它允许商用的许可证。
